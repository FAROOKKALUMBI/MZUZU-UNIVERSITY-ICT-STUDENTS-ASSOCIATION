# MUISA Academic Resources Vault

Welcome to the **Mzuzu University ICT Students Association (MUISA)** Academic Resources repository.

## 📁 Vault Structure

This repository maps all academic materials across undergraduate study levels:
- `LEVEL 1/` — First Year courses (End-User Computing, Intro to Programming, CCT, Calculus, Precalculus, etc.)
- `LEVEL 2/` — Second Year courses (Data Structures & Algorithms, Database Systems, Computer Networks, etc.)
- `LEVEL 3/` — Third Year courses (Web Development, Mobile App Dev, Systems Analysis, Operating Systems, etc.)
- `LEVEL 4/` — Fourth Year courses (Software Engineering, Network Security & Administration, IS Audit, Entrepreneurship, etc.)

---

## ⚡ Cloud Storage & Binary Payloads

Due to the size of the comprehensive resource vault (>77 GB of video lectures, high-resolution textbooks, lab recordings, and software tools), large binary files are hosted across MUISA's cloud storage network and linked directly within the interactive academic vault explorer on the website.

- **Total Catalogued Materials**: 6,730+ files
- **Catalogue & Search Index**: Maintained in `src/data/resourcesData.json` and `src/data/vaultHierarchy.json`
- **Interactive Portal**: Access via the [MUISA Website Resources Portal](/resources).
